# Подключение backend Discovery v1

`AppContainer` по умолчанию создаёт общий `BackendApi` и реальные репозитории для авторизации, главной, афиши, карты, ленты и комнат. URL задаётся в `Platform.android.kt` и `Platform.ios.kt`.

## Локальный запуск

Из каталога backend-dev запустите Compose из приложенного README. API доступен на `127.0.0.1:8080`; Android Emulator обращается к хосту по `10.0.2.2:8080`, iOS Simulator — по `127.0.0.1:8080`. На физическом Android подключите телефон по USB и выполните `adb reverse tcp:8080 tcp:8080`; приложение на устройстве использует `127.0.0.1:8080`. Для входа используйте `person1@example.test` или `person2@example.test`, код dev OTP — `0427`; для нового профиля — `new@example.test`. Dev backend ограничивает SMS тестовым номером `+15550100100`, поэтому для российского номера challenge вернёт `VALIDATION_ERROR`. Перед запуском Android-приложения backend должен быть healthy.

## Подключённые сценарии

- OTP challenge/verify, получение профиля `/v1/me`, завершение регистрации и ротация access/refresh token.
- `/v1/home` (быстрые категории, подборки с фильтрами и ближайшие события), `/v1/catalog/categories`, `/v1/events`, детали события, публикация, запись и список участников организатора. Афиша и список участников организатора проходят все страницы курсора.
- `/v1/catalog/map` для опубликованных событий, мест и активностей; поиск использует `/v1/catalog/search` и `/v1/catalog/search/suggestions`. Недавние запросы остаются на устройстве, как требует контракт. ID события совпадает с ID в афише и выдаче свайпов.
- Одиночные кандидаты и комнаты: создание, приглашение, вступление, запуск, голосование, завершение и long polling с переподключением.

Клиент хранит idempotency key до известного результата POST и повторяет запрос с тем же телом и ключом. Ответы room snapshot со старой версией игнорируются клиентом по монотонной версии.

## Ограничения API текущего стенда

Реализация Discovery v1 не предоставляет в runtime API отмену собственной записи, удаление события, загрузку пользовательской обложки, чат, платежи, отзывы и операции списков профиля. Эти экраны/действия ещё не следует считать синхронизированными с сервером. Для новых событий клиент отправляет категорию каталога, координаты, описание, цену и тип входа; выбранный локальный файл обложки пока не загружается.

Мок-репозитории оставлены для явного локального использования, но не подключаются по умолчанию. Для release-сборки ещё нужно задать production HTTPS origin.
