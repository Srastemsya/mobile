# Дизайн «Срастёмся»

Документация для дизайна и фронтенда. Начни с документа нужного сценария и открой указанный фрейм Figma. Для визуальной реализации используй макет, для действий и переходов — описание сценария. Если макет и описание расходятся, зафиксируй вопрос до реализации спорного поведения.

Перед проектированием прочитай [персоны и пользовательские маршруты](ux-personas-scenarios.md). В документе собраны восемь персон, шесть сквозных маршрутов и ссылки на экраны, которые покрывают их сегодня. Приоритеты и идеи в нём описаны как продуктовые гипотезы.

Для задач о поиске компании, участии и рекомендациях также прочитай [гипотезы из продуктового обсуждения](ux-meeting-discovery-concepts.md). Там собраны идеи для онбординга, публикации, состава компании, поиска по настроению и обратной связи.
