# Открытия

![Эталон Figma — Открытия](screens/280-8319.png)

**Фрейм:** [280-8319](https://www.figma.com/design/khewsPf7b4JVyBwJaCmO43/startap_design?node-id=280-8319). **Эталон:** 390 × 844 px. **Сценарий:** [полный UI-прогон](README.md).

## Вход и состояние

Главная вкладка «Открытия» открыта; внизу виден таб-бар с активным пунктом «Открытия».

## Видимые элементы

Логотип и колокольчик наверху; приветственный блок «Куда срастёмся сегодня?»; две быстрые плитки; синяя плитка «Свайпать события» с подписью «Найди своё идеальное», иллюстрацией стопки и круглой стрелкой; ниже заголовок «Популярное рядом» и горизонтальные карточки.

## Действия и переходы

Тап по всей плитке «Свайпать события» → экран 02. Вертикальная прокрутка ленты не сдвигает нижний таб-бар.

## Проверка UI

Плитка целиком остаётся нажимаемой, декор не перекрывает текст и стрелку; выбранная вкладка визуально активна.
