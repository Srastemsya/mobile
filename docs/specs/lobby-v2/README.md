# Комната v2 · весовой выбор в лобби

[Контракт комнаты v2](../../contracts/lobby-v2.md) · [Приёмка](acceptance.md) · [Discovery v1](../discovery-v1/README.md)

Бэкенд-надстройка над комнатами BE-D03: участники задают веса категорий в лобби, пул раундов ранжируется по суммарным весам, после исчерпания выбирается лучший по лайкам вариант. Публичное поведение фиксирует контракт комнаты v2 поверх Discovery v1 и мобильного API.

| Пакет | Результат | Зависимости | Ветка / база PR |
|---|---|---|---|
| [BE-L01](implementation.md#be-l01--веса-в-лобби) | `PUT /rooms/{id}/preferences`, веса в snapshot, доставка через long poll | BE-D03 | `be-l01` от `dev` |
| [BE-L02](implementation.md#be-l02--весовое-ранжирование-пула) | Пул старта и следующих раундов по баллам, пересчёт за лайки | BE-L01 | `be-l02` от `be-l01` |
| [BE-L03](implementation.md#be-l03--итог-при-исчерпании) | `TOP_LIKED` при исчерпании, `result.kind`, стабильность терминальных состояний | BE-L02 | `be-l03` от `be-l02` |

Пакеты строго последовательны: PR каждого следующего пакета базируется на ветке предыдущего (stacked). Одиночная выдача, лобби-UI мобильного клиента и правила Discovery v1 вне комнат не меняются. Мобильный клиент подключает веса отдельной очередью после стабилизации контракта.
