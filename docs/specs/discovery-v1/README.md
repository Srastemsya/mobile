Фронтенд может реализовывать экраны параллельно по контракту. На интеграционном стенде порядок проверок — каталог → публикация и запись → попадание опубликованного события в новые пулы. Чат, платежи, уведомления, подбор по настроению и экран карты реализуются отдельными задачами. Проверка выдачи событий для карты входит в этот срез.
