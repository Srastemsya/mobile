# Приёмка мобильного приложения · Лента

Проверять поведение мобильного приложения на Android и iOS против стенда [discovery-v1](../discovery-v1/README.md) (Compose, Nginx `127.0.0.1:8080`). Серверное поведение приёмкой не проверяется — оно покрыто [приёмкой бэкенда](../discovery-v1/acceptance.md). Сверка внешнего вида — с фреймами секции [280-10678](https://www.figma.com/design/khewsPf7b4JVyBwJaCmO43/startap_design?node-id=280-10678). Для комнаты нужны минимум два устройства или симулятора. Тестер проверяет поведение через UI и наблюдаемые эффекты, без чтения реализации.

| ID | Действие | Ожидаемый результат |
|---|---|---|
| F00-01 | Открыть вкладку «Лента», выбрать каждый режим, вернуться назад | Экран выбора режима соответствует макету, обе карточки ведут на свои сценарии, «Назад» возвращает без потери состояния вкладки. |
| F01-01 | В одиночном режиме выбрать «События», категорию, дату, бюджет и число человек; показать подборку | Чипы единственного выбора, дата доступна только для событий, выдача соответствует фильтрам. Невалидный бюджет или число человек < 1 блокируют отправку с подписью ошибки у поля. |
| F01-02 | Со свайп-экрана открыть «Изменить фильтры» | Открываются фильтры текущего режима с текущими значениями; изменение перезапрашивает подборку заново. |
| F02-01 | Свайпать карточки влево/вправо и кнопками, использовать отмену | Свайп и кнопка эквивалентны. Отмена возвращает предыдущую карточку и её решение можно изменить. На первой карточке отмена недоступна. Счётчик и прогресс соответствуют позиции. |
| F03-01 | В одиночном режиме лайкнуть карточку | Сразу открывается полноэкранный результат с данными карточки; «К месту»/«К мероприятию» открывает детали с полным DTO. |
| F03-02 | Пропустить все карточки порции при наличии следующих | Автоматически показывается заглушка «Обновляем подборку» без доступных действий, затем первая карточка новой порции. |
| F03-03 | Пропустить все карточки при исчерпанной выдаче | Экран «Больше вариантов нет» с кнопкой «Изменить фильтры», возвращающей к фильтрам с сохранёнными значениями. |
| F03-04 | Повернуть экран / свернуть приложение посреди пула | Текущая карточка, решения и возможность отмены сохраняются. |
| F04-01 | Создать комнату, скопировать ссылку, вступить вторым устройством | Лобби показывает рост числа участников без ручного обновления. Состояние «ссылка скопирована» соответствует макету. Кнопка старта активна только от двух участников и только у организатора. |
| F04-02 | Вступить по истёкшей ссылке новым пользователем | Понятное сообщение об истечении с предложением запросить новую ссылку; существующий участник по той же ссылке попадает в комнату. |
| F05-01 | Запустить комнату, пройти пул на всех устройствах с большинством за одну карточку | У всех одинаковые карточки в одном порядке. После последнего завершения все устройства показывают один и тот же матч. |
| F05-02 | Завершить раунд без большинства | Все устройства автоматически получают новый пул без ранее показанных карточек через состояние «Обновляем подборку». |
| F05-03 | Завершить свой проход раньше остальных, убить и перезапустить приложение | Экран «Ваш голос принят»; после перезапуска восстанавливаются свои голоса и ожидание, чужие голоса не видны. |
| F05-04 | Дождаться тайм-аута комнаты 30 минут | Заглушка закрытой комнаты, голосование недоступно, выход в выбор режима работает. |
| F06-01 | Получить `CURSOR_EXPIRED` (пауза > 30 минут в одиночном пуле) | Предложение обновить подборку; согласие загружает новый пул, отказ оставляет возможность изменить фильтры. |
| F06-02 | Отключить сеть во время загрузки пула и во время голоса | Состояние ошибки с повтором; после восстановления сети повтор успешен, дублей голосов и карточек нет. |
| F06-03 | Проверить экраны TalkBack/VoiceOver | Действия с иконками имеют доступные имена, загрузка и ошибки объявляются, фокус не теряется при смене карточки. |

В отчёте указать платформы, версию стенда, выполненные сценарии и ссылки на неизменённые артефакты прогонов по [правилам тестирования](../../../workflow/rules/testing.md).
