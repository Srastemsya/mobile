# Testing and evidence
Keep each test in its owning unit: services/<name>/tests/, apps/<name>/tests/, packages/js/tests/, packages/py/tests/. Each suite has run.sh that runs only its unit and creates one unique timestamped tests/reports/<stamp>.md per invocation (command, exit code, passed/failed/skipped). Scripts write factual reports; agents never edit those reports. Agents write separate tests/reviews/<stamp>.md on coverage/gaps/doc mismatches. tests/run-all.sh aggregates suite exit codes and report paths without replacing suite reports. Exclude legacy/. Never include secrets or sensitive payload plaintext. reports/<spec-id>/test_report.md only summarizes and links this evidence. Preserve any stricter existing project convention and resolve conflicts before moving tests.
