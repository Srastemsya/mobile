# FE-F00 · Повторная приёмка Android

Критерии AC-01–AC-09 из [исходной приёмки](../acceptance.md) сохраняются. Источники: [спецификация](../../../specs/feed-v1/FE-F00.md), [реализация](../../../../docs/specs/feed-v1/implementation.md), [F00-01](../../../../docs/specs/feed-v1/acceptance.md). Актуальный источник дизайна по указанию пользователя: [Figma Page 2](https://www.figma.com/design/khewsPf7b4JVyBwJaCmO43/startap_design?node-id=280-7618); ссылки исходного AC-02 заменяются этим источником. При расхождении дизайна и поведения обязательны требования спецификации; противоречия фиксируются.

AC-10: Android-сборка и запуск проходят, экран соответствует актуальному дизайну на Android. iOS исключён из приёмки по прямому указанию пользователя. Все обязательные критерии должны быть проверены на идентифицированной ревизии/сборке; недоступные проверки означают BLOCKED. Архитектуру подтверждает Developer автоматическими проверками, UI — независимый Tester. Серверная реализация вне объёма. FE-F01/FE-F04 могут оставаться документированными точками входа, как описано в исходной приёмке.
