## Changes and source evidence

- [Feed paging](../../../backend/runtime/swipes.py#L149) reads an immutable PostgreSQL candidate list by offset. PostgreSQL records the original filter values, account, expiry, ordering and cursor tokens in the same transaction. Replaying a cursor does not query catalog. An expired feed and its cursors are reclaimed opportunistically on later feed creation.
- [Room persistence](../../../backend/runtime/swipes_schema.py) retains version and expiry with the aggregate. [Room reads](../../../backend/runtime/swipes.py#L226), [joins](../../../backend/runtime/swipes.py#L307), starts and round mutations lock the same PostgreSQL row. Starting freezes the roster and party size. Used cards and accepted completions persist after replacement of a round. [Snapshots](../../../backend/runtime/swipes.py#L193) project the caller's votes only. [Round completion](../../../backend/runtime/swipes.py#L419) checks full coverage, serializes the transition, and chooses a strict majority by descending count then pool order.
- [Invitations](../../../backend/runtime/swipes.py#L289) use 32 bytes of randomness, store a digest for lookup, and return the token in the idempotent invite response. Nginx access logging and Uvicorn access logging are disabled. The routes and exception handlers do not log invite request or response bodies. Invitations do not appear in Room snapshots.
- [Version writes](../../../backend/runtime/swipes.py#L210) are made in PostgreSQL with state changes. [Post operations](../../../backend/runtime/swipes.py#L253), [round operations](../../../backend/runtime/swipes.py#L375) and snapshot expiry notify Redis after the database context commits. The [Redis ACL](../../../backend/runtime/keys.py#L33) limits room pub/sub to the room channel prefix. [Long polling](../../../backend/runtime/swipes.py#L454) checks authorization and membership before subscribe, consumes the subscribe acknowledgement and rereads, and rereads PostgreSQL and rechecks auth at the wait deadline. Short receive intervals detect disconnects. Context management releases the subscription on cancellation or exit. Nginx config disables response buffering and sets 35 seconds upstream read timeout.
- [Compose](../../../backend/compose.yaml) runs Swipes against its own PostgreSQL and gates startup on healthy dependencies. Readiness probes own PostgreSQL and Redis. Existing admin JWT and runtime recovery support already cover Swipes. Candidate and profile reads use the [documented internal HTTP routes](../../../docs/contracts/catalog-integration.md) for the current filtered snapshot and one participant's name. Catalog remains the owner of publication and Kafka.
- [Backend startup and fixtures](../../../backend/README.md) document the public setup, deterministic card sets and request-scoped dev clock. The override is ignored in production.
