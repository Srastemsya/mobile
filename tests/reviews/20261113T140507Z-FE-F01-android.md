## Observations

- Single-device entry opens a screen with top bar title «Фильтры», heading «Что ищем?» and context «Вы выбираете вместе на одном устройстве».
- PLACE hides the date control. EVENT exposes it. The Android date picker selected Nov 14, 2026 and the field displayed `14.11.2026` after confirmation.
- Server categories displayed as chips and wrapped across rows (PLACE: three chips on the first row and two on the second; EVENT: further fixture categories wrap onto additional rows).
- Visual comparison: title, heading, context and core chip treatment are present. The live app omits the Figma «Тип подборки» section label; its typography, spacing and controls render substantially larger than the 390×844 frame; its «Показать подборку» button occupies roughly 38% of the available content width while Figma's primary action spans almost the full content width. The reference frame shows a date field even with PLACE selected, while the live app hides it; hiding it follows the written FE-F01 contract. Dynamic server categories explain extra chip rows relative to the three-chip mockup. UI Kit ancestry/token usage cannot be proven from a screenshot alone.
- Negative budget `-14` blocked submission with field-associated “Введите неотрицательный целый бюджет”. Fractional budget `100.5` produced the same field error. With budget `100` and party size `0`, submit was blocked and “Укажите число человек от 1” appeared by the party field.
- Valid PLACE with budget ₽5,000 and party size 2 returned 20 visible “Стендовый вариант” cards. “Изменить фильтры” returned to the screen with budget `5000` and party size `2` restored.
- EVENT date picker defaulted to the emulator's current date (Nov 14, 2026); selecting it persisted as `14.11.2026`. EVENT All + that date + ₽5,000 returned the empty state. EVENT category “События для проверки свайпов” without date also returned the empty state. These outcomes do not show an app defect because staging data may have no candidates matching either query.
- EVENT All/no date/no budget returned 20 named candidates, including “Вечер джаза у моря”, “Прогулка к маяку”, and “Выставка современного искусства”. This establishes an available event fixture but does not establish expected membership under the narrower date/category filters.
