# Открытия

## Краткое описание

Стартовая вкладка помогает выбрать занятие поблизости через быстрые действия и подборки. Визуальный эталон и действия экрана заданы в [спецификации](../../../../../../../../docs/specs/swipe-ui/01-discovery.md) и [описании дизайна](../../../../../../../../docs/design/home.md).

## Бизнес-логика

- Вкладка «Открытия» активна при входе на главный экран; вертикальная прокрутка не перемещает таб-бар.
- Вся плитка «Свайпать события» открывает выбор устройства с типом «События» для следующего шага. Экран выбора не показывает таб-бар.
- «Подобрать под вайб» ведёт на карту; «Смотреть все» ведёт в афишу. Карточки «Популярное рядом» ведут на карту. Состав подборок приходит из `GET /v1/home` и может меняться.

## Архитектура

### Domain Layer

- `GetHome` — загружает содержимое экрана через `HomeRepository`.
- Модели: `HomeContent`, `HomeCollection`, `HomeQuickCategory`, `HomeUpcoming`; интерфейс `HomeRepository`.

### Data Layer

- `BackendHomeRepository` — читает `GET /v1/home` через общий `BackendApi` и переводит ответ в доменные модели. `MockHomeRepository` содержит локальные демонстрационные подборки.

### Presentation Layer

- `HomeViewModel` хранит `StateFlow<HomeUiState>` с содержимым, загрузкой и ошибкой; `refresh()` получает или повторяет запрос после завершения проверки регистрации в `NavigationMain`, чтобы защищённый `/v1/home` не отправлялся до восстановления сессии.
- `HomeScreen` рисует шапку, приветствие, две быстрые плитки и горизонтальную карусель. Переходы передаются через `onOpenFeed`, `onOpenEvents`, `onOpenMap` из `NavigationMain`; `MainViewModel.navigateToFeedWithEventsKind()` открывает следующий шаг.

## Зависимости

### Использует

- UI Kit [`:uikit`](../../../../../../../../uikit/README.md): `SrColors`, `SrType`, иллюстрации и обложки.
- [Лента](../feed/FEATURE.md) — выбор устройства после свайп-плитки.
- [Карта](../../../../../../../../docs/design/map.md) и [События](../../../../../../../../docs/design/events.md) — переходы из быстрых действий и подборок.

### Используется в

- `NavigationMain`, `BottomNavigationBar` и `AppContainer`.

## Особенности реализации

- Общие визуальные токены находятся в UI Kit; горизонтальная карусель прокручивается отдельно от вертикальной ленты.
- Системные status/navigation insets учитываются отдельно. Таб-бар рисуется вне прокручиваемого `HomeScreen`; пространство под подборками позволяет прокрутить нижнюю карточку выше таб-бара.
- Количество и названия подборок зависят от backend; две локальные обложки используются для первых карточек.
